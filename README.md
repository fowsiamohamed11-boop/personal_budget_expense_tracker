Personal Budget & Expense Tracker

About the Project

This is a simple Personal Budget & Expense Tracker created using HTML and CSS. It helps users enter and organize their expenses.

What I Built

Part 1 – HTML Structure

I created the basic structure of the Personal Budget & Expense Tracker using HTML.

Part 2 – Add Expense Form

I created an expense form with fields for the expense name, amount, and category. I also added a dropdown menu with different expense categories.

Part 3 – Expense Section

I created a section where users can view their expenses.

Part 4 – Interactive Element

I added a collapsible "How to use this tracker" section using the "<details>" and "<summary>" elements. I also added a hover effect to the expense table rows.
Part 5 – Advanced CSS Selectors

I used advanced CSS selectors, including descendant selectors, direct child selectors, position-based pseudo-classes, negation pseudo-classes, and focus states.

Technologies Used
